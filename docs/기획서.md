# Smart Rainwater Monitoring System(SRMS)

> 공공 API를 활용한 빗물 재활용 시설 디지털 트윈 모니터링 시스템

---

## 프로젝트 개요&요구사항 분석

SRMS는 공공 API로 수집한 기상 데이터를 활용해 빗물 재활용 시설(Rainwater Recycling Facility)의 설비 상태를 모니터링하는 웹 기반 디지털 트윈 시스템이다.

수집한 데이터를 표준화된 SensorData 구조로 변환하고, 이를 3D 설비 모델과 연동해 시설 상태를 직관적으로 시각화한다. 또한 센서 데이터를 기반으로 정상·주의·위험 상태를 판단하고 사용자에게 이상 징후를 제공하는 기능을 구현한다.

---

### 설비 구성

| 설비 | 역할 |
| --- | --- |
| 저장탱크 | 빗물 저장 |
| 펌프 | 저장된 물 이동 |
| 필터 | 빗물 정화  |
| 재사용 탱크 | 정화된 물 저장 |

---

### 주요 기능

* 기상 데이터 조회
* 센서 데이터 관리
* 3D 설비 시각화
* 설비 상태 표시
* 설비 선택 및 상세 정보 조회
* 이상 탐지 및 경고

### SensorData

```ts
interface SensorData {
    timestamp;
    sensorId;
    sensorName;
    sensorType;
    value;
    unit;
    location;
    status;
    isAnomaly;
    source;

```

## 기능 설계

* 기상 데이터 조회: Open API를 통해 기상 데이터를 조회한다.
* 데이터 표준화: Open API 데이터를 SensorData 형태로 변환한다.
* 설비 시각화: SensorData를 3D 설비와 연결해 설비 상태를 표시한다.
* 설비 선택: 설비를 클릭하면 상세 정보를 표시한다.
* 이상 탐지: 센서 데이터를 기반으로 정상·주의·위험 상태를 판단하고 경고를 제공한다.

## 기술 스택

| 구분 | 사용 기술 |
| --- | --- |
| 프론트엔드 | React, TypeScript, Vite |
